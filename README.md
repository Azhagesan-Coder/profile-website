# Azhagesan Ranganathan — Profile Website

A responsive personal portfolio based on Azhagesan's supplied resume. Built with HTML and CSS; no installation, build step or JavaScript required.

## Preview

Open `dist/index.html` in a browser, or serve `dist` with any static web server.

## Edit

- Content: `dist/index.html`
- Design: `dist/styles.css`
- Downloadable resume: `dist/Azhagesan.pdf`

Google Fonts supplies DM Sans and Space Grotesk; the site falls back to local sans-serif fonts offline.

## GitHub Pages

Upload the contents of `dist` to a repository root and enable GitHub Pages for the main branch / root. Alternatively, retain this directory structure and configure a Pages workflow to upload `dist`.

The site uses the employment dates listed in the resume. The latest role ends in June 2026; it does not claim current employment. No project names, client names or achievements have been invented.
